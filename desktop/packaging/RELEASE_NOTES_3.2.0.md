## What's new in 3.2

**Agents.** A third mode beside Normal and Plan. In agent mode the studio splits your message into the separate tasks it needs and hands each to an agent: one agent a task, each with its own English name and colour. The agents work at the same time — with the internet on, each searches and reads the pages its task needs — and come back with short reports; the model answers from them, and says plainly when something was not found instead of filling it in from memory.

The crew is shown in the chat as a row of coloured circles with two eyes, one an agent, each with its name; a circle pulses while its agent works. Open the card to see each agent's task, its searches and pages, and its report. Agents work with a local model or with any online model you have a key for; a local server with one slot takes them in turn.

**Modes as icons.** Normal, Plan and Agents sit side by side as icons; the one that is chosen shows its name.

The same agents are in AhoosAI's online studio, its Telegram bot, Terminal CLI and the API (`nimbus_agents`).
